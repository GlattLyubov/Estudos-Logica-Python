## Estudando Lógica com Python 
Este mini programa ou código serve para aplicar os meus estudos e conhecimentos de lógica com Python. A ideia é usar comandos como While True e estruturas de condição para criar a lógica encadeada do programa.

Cada if, elif e else junto com comando break tem uma função. A ideia é realmente ir pelo caminho mais difícil e forçar meu cerebro a entender como cada comando funciona. 

O jogo é simples, você escolhe o número respectivo a um animal e a "máquina" vai advinhar apenas com perguntas de "sim" ou "não". Sei que preciso melhorar muitas coisas nesse código, mas a ideia é realmente essa, primeiro aprender para depois melhorar.
